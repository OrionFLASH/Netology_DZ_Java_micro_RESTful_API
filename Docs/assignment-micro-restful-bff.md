# Задание: RESTful API и паттерн BFF

**Преподаватели:** Иван Бочаров, Виктор Лоскутов, Георгий Власов

## Цели

- Организовать взаимодействие микросервисов через RESTful API
- Работать с паттерном BFF (Backend-for-Frontend)

## Инструменты

- IntelliJ IDEA
- HTTP-клиент

## Описание

Необходимо создать два микросервиса с REST API для BFF-микросервиса. BFF получает клиентский запрос, вызывает оба микросервиса, собирает информацию в один объект и возвращает клиенту.

## Микросервис пользователей

- HTTP-доступ к данным
- `RestController` из `spring-boot-starter-web`
- Endpoint: `GET /api/users/{userId}`

## Микросервис заказов

- HTTP-доступ к данным
- `RestController` из `spring-boot-starter-web`
- Endpoint: `GET /api/orders/by-user/{user}`

## BFF-микросервис

- HTTP-доступ к данным
- `RestController` из `spring-boot-starter-web`
- Endpoint: `GET /api/site-bff/user/{userId}`
- При запросе обращается к обоим микросервисам, агрегирует данные и возвращает результат
- **Не хранит данные** — только агрегирует и преобразует

## Модели данных

### User
- Id, ФИО, адрес доставки, номер телефона, email

### Order
- Id, UserId, сумма заказа, валюта заказа, список позиций в заказе

### BFF
- Общая модель с информацией о пользователе и его заказах

## Тестирование

1. Запустить все три микросервиса
2. Отправить запрос на BFF
3. Проверить агрегированный ответ
